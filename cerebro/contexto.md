# 📄 Contexto

- **Problema:** como usuario de Ecobici, ir y volver del trabajo en bici depende de encontrar una bici al salir y un lugar libre al llegar.
- **Producto:** entender cómo se mueve la ciudad en bici (histórico 2010–2026, por comuna, barrio y hora) y predecir la disponibilidad de cada estación.
- **Objetivo profesional:** mostrar el camino Data Engineer → AI Data Engineer con prácticas de ingeniería de software de punta a punta.
- **Fuentes:** datos abiertos de Buenos Aires (recorridos y usuarios por año, CC-BY-2.5-AR), GBFS (requiere credenciales, a verificar), Open-Meteo y feriados.
- **Stack:** Python 3.13 + uv, Postgres 16 + PostGIS, dbt, object storage S3, Metabase; después Dagster, FastAPI, React, MLflow, LightGBM y Evidently.
- **Fase actual:** F0 · Fundaciones.
